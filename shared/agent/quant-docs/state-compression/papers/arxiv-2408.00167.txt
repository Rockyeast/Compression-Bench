5.1   Adaptive Key-Value Cache Compression
As depicted in Figure 1, F INCH iteratively pro-
cesses a document segmented into chunks, each
evaluated in conjunction with a user prompt, and
uses the self-attention to identify which K,V pairs
to keep in the cache. In analogy to the long-term
memory involving the capacity to recall words,
concepts, or numbers (Chauvet, 2024), we say that
these pairs can act as the semantic memory for the
model. The document is reduced to its significant
elements and processed in the Generation stage.
