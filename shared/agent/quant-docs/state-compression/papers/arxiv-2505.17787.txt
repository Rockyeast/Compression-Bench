prefill stage is slow [6, 10]. To reduce the time-to-first-token (TTFT),
we propose the intra-core pipeline (ICPI) and inter-core paral-

the computation flow within the core-level into multiple stages.

core. Moreover, the 𝑖 𝑡ℎ core passes its result to the (𝑖 + 1)𝑡ℎ core
