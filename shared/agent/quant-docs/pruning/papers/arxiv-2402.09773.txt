Figure 2: The overall framework of NutePrune. The pruned model is frozen and incorporated with learnable masks
and LoRA. During pruning, the model is guided by numerous teachers. Before pruned to the target sparsity (e.g.
30%), it learns from teachers with a fixed capacity gap. Once the target sparsity is achieved, it continues to learn
from all previous teachers from weak to strong. All these teachers are derived from snapshots of the student model
itself. Since only the mask and LoRA modules are snapshotted, the additional memory cost is negligible.
