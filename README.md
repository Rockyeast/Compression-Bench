Pinned offline reference library for Compression-Bench.

Contains 21,388 selected paper and upstream-source files, preserving the existing source selection, local adaptations, extracted text, licenses and executable permissions. Ten archives contain approximately 2.70 GB of compressed data.

Download all ten archives and reference-lock.json. Use scripts/prepare_references.py with --archive-dir to restore them, or use automatic downloads after the updated preparation scripts are available in the code repository. SHA256SUMS provides archive-level verification; reference-lock.json also contains per-file checksums.

These are reference assets, not model weights or experiment outputs. The release tag points to a small manifest-only snapshot so the reference files do not enter Git history.
